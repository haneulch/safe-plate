# 🍽️ SafePlate Korea

> **식이 제약이 있는 여행자를 위한 AI 기반 안심 식당·메뉴 판정 서비스**
> "불안한 외식"을 "확신 있는 한 끼"로 바꿉니다.

관광데이터 활용 공모전 출품작 — 과제 5번
**「맞춤형 식당 정보 부족으로 인한 만성질환자의 외식 불안감 발생 및 여행 만족도 저하」** 해결

---

## 1. 프로젝트 개요

만성질환자, 알레르기 보유자, 종교식 준수 외국인 관광객은 한국 여행 중 "이 식당에서 내가 먹을 수 있는 메뉴가 있는가?"를 확인할 방법이 없어 외식 자체를 불안해하거나 포기합니다.

SafePlate Korea는 사용자가 **식이 제약 프로필을 한 번 등록**하면, 한국관광공사 TourAPI의 음식점·메뉴 데이터를 AI로 분석하여 여행지 주변 모든 식당과 메뉴를 **안심 / 조건부 / 주의** 3단계 신호등으로 실시간 판정합니다. 단순 필터가 아니라, 개인 프로필과 메뉴 재료를 대조하는 **판정(verdict) 엔진**이 핵심입니다.

## 2. 주요 기능

| 기능 | 설명 |
|---|---|
| 🌏 **웰컴 & 국가 선택** | 첫 화면에서 국적을 선택하면 해당 언어로 전체 UI 제공 (한국어·영어·일본어·중국어·아랍어, 미지원 언어는 영어 폴백, 아랍어 RTL 지원) |
| 👤 **식이 제약 프로필** | 만성질환 6종 + 알레르겐 13종 + 종교·신념 식단 7종 선택. 국적은 식단을 단정하지 않고 프로필 '제안'만 제공 |
| 🚦 **식당·메뉴 신호등 판정** | 프로필 변경 즉시 모든 식당·메뉴의 판정이 재계산. 판정마다 근거 사유("한국 간장은 밀 함유가 많아요" 등) 표시 |
| 💳 **식이 제약 안내 카드 (Dietary Care ID)** | 신분증 스타일 카드에 "먹을 수 없어요 ✕ 돼지고기 ✕ 땅콩"을 **한국어로** 표시 — 식당 사장님에게 보여주는 오프라인 소통 도구. 카드번호·QR·발급일 포함 |
| 🍚 **국가별 인기 한식 추천** | 한국관광공사 외래관광객조사 기반 국가별 인기 메뉴에 **내 프로필 판정을 결합**하여 표시 |
| 📍 **지역 전환** | 외국인 밀집 관광지(서울 명동) ↔ 지방 관광지(전주 한옥마을) 전환 시연 |

## 3. 판정 엔진 (Verdict Engine)

### 3-1. 지원 프로필

**만성질환 (6종)**
- 고혈압·신장질환 — 나트륨 등급 판정
- 당뇨 — 당류 등급 판정
- 통풍 — 퓨린 판정 (진한 육수·내장·해산물)
- 고지혈증 — 포화지방 판정
- 위염·역류성 식도염 — 맵기·자극 판정
- 셀리악병 — 글루텐 판정 (밀 포함 시 '주의', 간장 양념 시 '글루텐 확인' 조건부)

**알레르겐 (13종, 식약처 표시대상 기준)**
땅콩 · 견과류(호두·잣) · 갑각류 · 조개·오징어류 · 생선 · 우유 · 계란 · 밀 · 메밀 · 대두 · 돼지고기 · 쇠고기 · 닭고기

**종교·신념 식단 (7종)**
- 할랄(이슬람): 돼지고기·주류 불가, 기타 육류는 할랄 도축 확인 조건부
- 코셔(유대교): 돼지·갑각류·조개 불가 + **육류·유제품 혼합 금지** 규칙
- 힌두교: 쇠고기 불가
- 사찰식(불교): 육류·어패류 + **오신채(마늘·파 등)** 불가
- 비건 / 채식(락토오보) / 페스코 3단계 채식

### 3-2. 판정 규칙

```
메뉴 재료 태그 (돼지/소/닭/조개·오징어/대두/메밀/오신채 등)
  × 사용자 프로필 (질환·알레르겐·식단)
  → 안심(G) / 조건부(Y) / 주의(R) + 근거 사유 생성
식당 종합 판정 = 메뉴 판정 집계 (안심 메뉴 n개 / 조건부 n개 / 안심 메뉴 없음)
```

- 알레르겐 직접 포함 → 주의(R), 제외 주문 가능 메뉴 → 조건부(Y), 교차오염 가능 → 조건부(Y)
- 모든 판정은 단정이 아닌 **"추정 등급"** 으로 표기하고, 주문 전 매장 확인을 안내

## 4. 데이터 아키텍처

| 데이터 | 역할 | 비고 |
|---|---|---|
| **한국관광공사 TourAPI** (필수) | 음식점 목록(areaBasedList, contentTypeId=39), 상세 메뉴 텍스트(detailIntro의 firstmenu/treatmenu), 다국어 관광정보 | 공모전 필수 API — 핵심 기능에 사용 |
| 한국관광공사 외래관광객조사 | 국가별 인기 한식 추천 근거 | |
| 식약처 전국통합식품영양성분 표준DB ('음식') | 표준 메뉴의 나트륨·당류 정량 근거 | 메뉴명 매칭 |
| 식약처 식품영양성분DB API | 영양성분 실시간 조회 | |
| 음식점 인허가 데이터(LOCALDATA) | 폐업·휴업 식당 필터링 (헛걸음 방지) | |
| 음식점 위생등급·모범음식점 | 조리 신뢰도 배지 | |
| 식약처 푸드QR (알레르기·원재료 정보) | 가공식품(편의점·카페) 판정 확장 로드맵 | |

**AI 분석 레이어**: TourAPI의 비정형 메뉴 텍스트("곱창전골, 해물파전…")를 LLM으로 파싱해 재료 태그·알레르겐·식단 적합성을 추정 → 표준DB 매칭으로 정량 보정 → 사용자·식당 제보로 검증하는 파이프라인.

## 5. 실행 방법

프로토타입은 의존성 없는 단일 HTML 파일입니다.

```bash
# 브라우저에서 바로 열기
open safeplate-korea.html
```

- 데모 데이터로 동작하며, 실서비스 연동 시 각 식당 객체를 TourAPI 응답으로 치환하는 구조로 설계됨
- TourAPI 인증키는 [공공데이터포털](https://www.data.go.kr)에서 「한국관광공사_국문 관광정보 서비스」 활용신청 후 발급

```
예시 호출:
GET http://apis.data.go.kr/B551011/KorService1/areaBasedList1
  ?serviceKey={인증키}&contentTypeId=39&areaCode=1&MobileOS=ETC&MobileApp=SafePlate&_type=json
```

## 6. 기술 스택

- **Frontend**: 순수 HTML/CSS/JS 단일 파일 (모바일 웹, max-width 420px)
- **i18n**: 5개 언어 딕셔너리 + 영어 폴백, 아랍어 RTL 대응
- **디자인**: 셀라돈 그린 브랜드 컬러 + 신호등 3색 기능색, Gowun Batang(디스플레이) × IBM Plex Sans KR(UI)
- **판정 엔진**: 클라이언트 사이드 규칙 기반 (실서비스: 서버 사이드 + LLM 재료 추정)
